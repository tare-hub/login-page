# 🔐 Modern Login Page

A modern, responsive, and user-friendly login page designed with a clean interface and an attractive visual experience. This project demonstrates a simple authentication interface with a focus on usability, responsive design, and clean frontend development.

## ✨ Features

- Modern and clean user interface
- Responsive design for desktop, tablet, and mobile
- Email and password input fields
- Password visibility toggle
- Form validation
- Remember Me option
- Forgot Password link
- Sign Up navigation
- Smooth transitions and interactive elements

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🚀 Getting Started

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder:

   ```bash
   cd login-page
   ```

3. Open `index.html` in your browser.
